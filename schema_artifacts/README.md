# Schema Artifacts

This directory groups the static, tracked files used by the schema pipeline.

- `inputs/` contains checked-in reference material that is not generated by this
  repo.
- `releases/` contains generated release schema JSON and provenance sidecars.
- `reports/` contains generated schema review evidence and crosswalk reports.

Rebuild release outputs and reports with:

```sh
swatref schema build
swatref schema ranges
swatref schema field-map
```
